# QuietPaste 🔒

A secure and lightweight text-sharing application built with Flask and SQLite. Share text or code snippets through private links with automatic expiration.

## ✨ Features

- 🔐 Private link-based text sharing
- ⏳ Automatic expiration (10 minutes, 1 hour)
- 👁️ One-time view links
- 📱 Simple and responsive user interface
- 🛡️ Safe text rendering to prevent HTML injection
- 🗄️ SQLite database for data storage
- 🧪 Tests for expiration, one-time access, and secure rendering

## 🛠️ Tech Stack

- **Backend:** Python, Flask
- **Database:** SQLite
- **Frontend:** HTML, CSS
- **Testing:** Pytest

## 🚀 Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd QuietPaste
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   python app.py
   ```

5. Open in your browser:

   ```text
   http://127.0.0.1:5000
   ```

## 🧪 Run Tests

```bash
pytest
```

## 📌 Project Purpose

QuietPaste provides a simple and secure way to share temporary text and code snippets without keeping them permanently accessible.
